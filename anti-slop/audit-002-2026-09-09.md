# Audit 002 - Redesign "Not AI-Made" (2026-09-09)

Mode: antislop DURING a visual redesign. Arah desain diambil dari handoff Claude Design
(auteur) yang diadaptasi ke stack React + Tailwind + GSAP dan ke data nyata situs.
Referensi: `designs/JasKapital Landing.html`, `DESIGN.md`.

## Yang diubah (dari audit-001 ke desain baru)

- **Meninggalkan pola template AI** yang sebelumnya masih ada:
  - Hero + statistik dalam kartu ber-border gradien -> kini editorial: headline serif besar +
    panel metrik strip full-width tanpa kartu.
  - Baris overline + dot hijau + garis gradien gold->green pada tiap section -> kini eyebrow
    dengan rule emas, `section-head` editorial (judul kiri, catatan kanan, hairline bawah).
  - Kartu icon (lucide) untuk 4 pillar -> kini kolom bernomor (01-04) dengan pembatas hairline
    (tanpa icon, tanpa shadow, tanpa card box).
  - Foto portfolio -> greyscale (menghilangkan noise, menyatukan 3 foto sebagai set editorial).
  - Footer 3/4 kolom -> satu baris editorial brand + copyright.
- **Palet baru yang terikat logo + AA-safe**: navy (#0A1628), gold (#B8860B, hover #D6A21A),
  gold-deep (#7A5C08 untuk teks emas di atas terang), green (#2E7D4A), paper (#FBFAF8 - kertas
  hangat), ink/ink-soft, line (#DCD8D0), cream (#EFEBE2). Menghapus palet dingin bekas.
- **Motion berpurpose**, semua dipagari `prefers-reduced-motion` via `gsap.matchMedia`.
- **Figur & konten dipertahankan (real)**: 3 perusahaan + deskripsi + link asli; email & telepon
  asli; statistik asli. Tidak ada em dash (R-02), tidak ada testimoni/klaim palsu (R-18/R-36).

## Delivery Gate (antislop) - hasil

Block 1 - Hard Gate: PASS (tidak ada em dash; target tap >= 44px; tidak ada statistik tanpa
sumber; tidak ada testimoni; aset memakai foto/logo nyata; semua nav menunjuk section yang ada;
tidak ada kontrol mati; tidak ada klaim palsu).
Block 2 - Purpose-Gate: PASS (gradien hanya motif column-rhythm di hero pada 6% opacity dengan
alasan tertulis di DESIGN.md; tanpa glassmorphism/grid dekoratif lain; animasi punya tujuan).
Block 3 - Liveliness (dials ENERGY 2 / RHYTHM 3 / MOTION 2): ditetapkan dan konsisten dengan
komposisi section yang bervariasi.
Block 4 - Craftsmanship: PASS (C-1 alasan tertulis per keputusan di DESIGN.md; C-2 semua
interaktif berfungsi; C-3 tidak ada section isi template; C-4 theme/breakpoint diperiksa;
C-5 klaim dapat diverifikasi / tidak dibuat-buat).

## Verifikasi

- `npm run build` (tsc + vite): PASS, tanpa error.
- `npm run lint`: PASS untuk semua file yang diubah; 8 error tersisa semuanya pra-ada di
  `components/ui/*` (boilerplate shadcn, di luar scope).
- Cek render: dev server Vite tanpa error di log; kelas desain custom
  (bg-paper, text-cream, text-gold-deep, text-ink-soft, border-line, dll) terkompilasi penuh;
  hover:bg-gold-light (#D6A21A) ada di CSS bundle.
- Kontras: gold-deep #7A5C08 di atas paper ~6.0:1 (AA); ink-soft ~7.2:1; teks navy-light
  (#B9C0CC / #8D97A6) di atas navy lolos; gold serif 64px di atas navy ~5.7:1.
- Karena tidak ada browser headless yang tersedia, click-through diverifikasi lewat inspeksi kode
  (halaman statis single-page): nav/CTA/email/visit-website semuanya menunjuk target nyata.

## Catatan

- Desain adalah adaptasi dari handoff; detail yang menyintesis data nyata (kontak, deskripsi
  perusahaan, statistik, gambar) sengaja tetap memakai sumber asli (R-23, R-38).
- Sisa pekerjaan untuk dev: pastikan Chrome auteur tetap; `designs/` hanya referensi, bukan
  bagian build.
